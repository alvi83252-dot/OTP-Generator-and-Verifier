Validity rules

  • Demo OTP: {{ digits }} digits from a cryptographic generator, valid for {{ validity }} seconds.
  • You may try again while the bar is still moving. A wrong code is a failure, not a lockout.
  • Letters, the wrong length, and empty input are invalid. They do not count as an attempt.
  • At the deadline or later, a right code and a wrong code are both expired. Input locks for {{ lockout }} seconds.
  • The bar is a visualizer. The server clock decides. A refresh does not clear a lock.
  • TOTP (RFC 6238): HMAC-SHA1, {{ totp_step }}-second steps, skew of +/- {{ totp_skew }} step. No lockout.
  • HOTP (RFC 4226): HMAC-SHA1, look-ahead 0. The counter moves only after a correct code.
